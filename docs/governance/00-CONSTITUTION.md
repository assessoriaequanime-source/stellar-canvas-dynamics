# SingulAI Constitution

## Fundamental Principles

1. Stability before features.
2. Every change must be reversible.
3. Every architectural decision must be documented.
4. No breaking changes without migration.
5. Build must pass before and after modifications.
6. No automatic commits.
7. Documentation is mandatory.
8. Architecture must remain modular.
9. Prefer extension over modification.
10. Every AI agent must respect this constitution.
